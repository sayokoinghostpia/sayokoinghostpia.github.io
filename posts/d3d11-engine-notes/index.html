从 hw3d 出发：Direct3D 11 渲染管线笔记

以 hw3d 为线索，梳理 D3D11 的设备、交换链、渲染管线和常量缓冲。

图形学 C++

目录

最近在跟着 Planet Chili 的教程写 hw3d， 一个用 Direct3D 11 实现的 3D 小引擎。这里不打算写成完整的 D3D11 教程， 只想把目前理解的几个核心对象和管线阶段串起来，方便以后回头查。

设备、上下文与交换链

D3D11 里最先遇到的是三个对象： ID3D11Device 负责创建资源， ID3D11DeviceContext 负责发出绘制命令， IDXGISwapChain 负责把渲染结果呈现到窗口。 创建它们最省事的方式是调用 D3D11CreateDeviceAndSwapChain，一次性把描述填好： 

DXGI_SWAP_CHAIN_DESC sd = {};
sd.BufferCount = 2;
sd.BufferDesc.Format = DXGI_FORMAT_R8G8B8A8_UNORM;
sd.BufferUsage = DXGI_USAGE_RENDER_TARGET_OUTPUT;
sd.OutputWindow = hWnd;
sd.SampleDesc.Count = 1;
sd.Windowed = TRUE;

D3D11CreateDeviceAndSwapChain(
    nullptr, D3D_DRIVER_TYPE_HARDWARE, nullptr, 0,
    nullptr, 0, D3D11_SDK_VERSION,
    &sd, &swapChain, &device, nullptr, &context);

交换链通常维护两个后台缓冲：一个正在显示，另一个在后台绘制。 调用 Present 时交换，画面看起来就连续了。 BufferDesc.Format 和窗口的像素格式要对齐， 否则容易得到一片黑屏或者颜色发灰。

渲染管线的几个阶段

把一帧画出来，大致会经过这些阶段：

  • 输入装配（IA）：从顶点缓冲和索引缓冲读取几何数据。
  • 顶点着色器（VS）：把顶点从模型空间变换到裁剪空间。
  • 光栅化（RS）：把三角形变成屏幕上的像素片段。
  • 像素着色器（PS）：决定每个像素最终的颜色。
  • 输出合并（OM）：处理深度、模板和混合，写入渲染目标。

这些阶段在 D3D11 里不是手写循环，而是通过设置管线状态、绑定资源和调用 Draw 来驱动。理解每个阶段「输入什么、输出什么」， 比记住 API 名称更有用。

着色器与常量缓冲

顶点变换需要矩阵。实践中通常把 world、view、projection 放进一个 cbuffer（常量缓冲），由 CPU 每帧更新，再绑定到管线上。 一个最小的顶点着色器大概是这样： 

cbuffer Transform : register(b0)
{
    matrix world;
    matrix view;
    matrix projection;
};

struct VSInput
{
    float3 position : POSITION;
    float3 color    : COLOR;
};

float4 VSMain(VSInput input) : SV_POSITION
{
    float4 clip = mul(float4(input.position, 1.0f), world);
    clip = mul(clip, view);
    clip = mul(clip, projection);
    return clip;
}

常量缓冲的结构要和 C++ 侧的结构体对齐，注意打包规则和 16 字节边界。 如果画面莫名其妙地扭曲，先检查矩阵是不是按行主序/列主序传错了， 再检查常量缓冲有没有成功绑定。

从教程到自己的东西

跟着教程敲代码很容易产生「我懂了」的错觉。真正开始改的时候， 问题才会暴露：窗口大小变化时交换链要不要重建？渲染目标什么时候释放？ 哪些资源应该由 RAII 管理？这些问题没有唯一答案，但每一次修好都会让 引擎更接近「自己的」。
