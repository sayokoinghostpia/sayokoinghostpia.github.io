你好，世界：这个博客的第一篇文章

关于开博缘由、这里会写什么，以及这个站点是怎么搭起来的。

随笔 建站

目录

这是这个博客的第一篇文章。写它的目的很简单：给之后的技术笔记和生活记录 找一个不会被信息流冲走的地方。

为什么要有自己的站点

社交平台很适合快速分享，但不适合长期整理。一个自己的站点可以自己决定 结构、排版和去留，也可以把零散的笔记慢慢串成一条线。更重要的是，做这个 站点的过程本身就是一次练习：写 HTML、调 CSS、用 JavaScript 加一点交互， 再把它发布到公网。

这里会写什么

  • 图形学与 C++：正在学的 Direct3D 11、渲染管线和工程习惯。
  • Web 与工具：构建工具、静态站点、前端基础。
  • 随笔：项目进展、踩坑记录和一些生活碎片。

文章不会追求大而全，更多是「把一件事讲清楚」的短笔记。如果某篇内容对你有用， 那当然最好；如果没有，也可以把它当成我的公开草稿本。

这个站点怎么搭的

站点是一个纯静态项目：页面是手写的 HTML，样式用原生 CSS，交互用原生 JavaScript；构建工具是 Vite。构建时会生成一个 dist/ 目录， 里面是最终要发布的文件。然后把这些文件复制到 GitHub Pages 仓库的根目录， 推送到 main 分支，GitHub 就会自动重新发布。

因为是纯静态站点，所以没有数据库、没有后端，也没有登录和评论。 换来的是简单、快、便宜，而且所有内容都在自己的仓库里。

下一步

先把结构跑通，再慢慢把内容换成真正想写的东西。之后可能会加代码高亮、 标签归档，或者把写作流程换成 Markdown。不过在那之前，先让这个站点上线。

慢慢写，持续写。比起一次写完，更重要的是下一次还会回来。
